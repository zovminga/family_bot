Что измерено:
- Штатные тесты: 46 проходят.
- Тесты-воспроизведения: 24 теста, все красные, то есть ошибки подтверждены. Тесты
  лежат в `tests/known_bugs/` (пункт 0.4).

## 3. Дизайн: каким проект станет

### 3.1 Принципы

1. **Трата не теряется и не дублируется.** Каждая запись в Sheets либо прошла, либо
   пользователь видит ошибку и повторяет без дублей.
2. **Одно место для каждого правила.** Валюта, разбор строки, курс, категория описаны один
   раз и используются ботом и Dashboard.
3. **Бот на русском.** Все тексты, кнопки, числа и ошибки — по-русски.
4. **Частый сценарий — одно сообщение.** «кофе 350» текстом, голосом или фото дают
   одну и ту же карточку черновика.
5. **Код можно проверить тестом без сети.** Внешние вызовы проходят через интерфейсы с
   заглушками. Импорт модулей ничего не загружает из сети.

### 3.2 Устройство модулей

```
family_bot/
  app.py            сборка Application: обработчики, обработчик ошибок, сохранение состояния, post_init
  config.py         Config: категории, пресеты, валюты, ALLOWED_USERS, часовой пояс — грузится в post_init, лежит в bot_data
  currency.py       реестр валют: символ, ISO, русские слова; из него — кнопки, промпт, разбор
  flows/
    manual.py       ручной ввод
    preset.py       ⚡ пресеты (сейчас flow_preset.py)
    stats.py        статистика; состояние запроса — dataclass StatQuery
    draft.py        карточки черновиков: обработчики Telegram для draft_expense
  draft_expense.py  черновики с id; запись одним append_rows
  expense.py        ExpenseRecord; запись по заголовкам листа
  sheets.py         SheetsClient; вызовы через asyncio.to_thread
  sheet_data.py     разбор строк → Row (dataclass), общий для бота и Dashboard
  analytics.py      расчёты без I/O; курс передаётся снаружи
  fx.py             курсы валют, общий для бота и Dashboard
  llm.py            клиент Claude с таймаутом, разбор JSON из ответа
dashboard/          импортирует общие модули как пакет, без правки sys.path
```

Изменения в поведении:

- **Черновики.** У каждого черновика свой короткий id. Кнопки содержат его:
  `vx:<id>:save`. Черновики лежат в словаре по id. Сохранение — один вызов
  `append_rows`. Повторное нажатие на сохранённую карточку оставляет «✅ Сохранено».
- **Кнопка «домой».** Одна в `fallbacks` диалога. Чистит ключи только своего сценария,
  черновики не трогает.
- **Ошибки.** Общий обработчик пишет подробности в лог, а пользователю отвечает:
  «❌ Не сохранилось. Попробуйте ещё раз». Ошибки Claude: «Не разобрал, введите вручную».
- **Состояние.** Recent currencies хранятся в листе `Users`. Draft живёт в памяти бота.
  После деплоя старая карточка отвечает «Черновик устарел после обновления бота, отправьте
  ещё раз». Тексты кнопок меню входят в `entry_points`, поэтому меню работает после деплоя.
- **Время.** «Сегодня» считается в часовом поясе из настройки `TZ_NAME`
  (по умолчанию `Europe/Belgrade`).
- **Запись в лист.** `RAW` вместо `USER_ENTERED`: комментарий не превращается в формулу.

### 3.3 Сценарии бота после изменений

- **Текстом:** «кофе 350» → карточка черновика → «✅ Сохранить». Одно сообщение, одно нажатие.
- **Вручную:** последняя валюта стоит первой кнопкой. Комментарий и дата — одна кнопка
  «✅ Сегодня, без комментария». Сумма принимает «350», «1 200», «350 дин».
- **После сохранения:** «✅ Сохранено: Еда — 350 дин, 19.11.2026» и кнопка «↩️ Отменить».
- **Карточка черновика:** кнопки «✏️ Сумма», «👤 Кто», категория, валюта, сохранить, отмена.
- **Статистика:** кнопка «Этот месяц» — сразу итог, топ категорий и разбивка по людям.
- **Сводка:** 1-го числа бот сам присылает итог прошлого месяца (`JobQueue`).
- **Выбор валюты** — при вводе траты и при пересчёте в статистике:
  - первые три кнопки — Recent currencies этого User, с флагами: `🇷🇸 дин`, `🇨🇳 CNY`.
  - кнопка «🌍 Другая» открывает список всех валют сервиса курсов по страницам. Код или
    название можно ввести текстом: «юань», «GEL».
  - выбранная валюта попадает в Recent currencies.
- **Пересчёт в статистике:** по текущему курсу на момент запроса. Цель — любая валюта из
  списка, а не только валюты из Data. Курсы одного запроса берутся одним обращением к
  сервису и кэшируются на 1 час.

### 3.4 Dashboard после изменений

- Первый экран: «Этот месяц: X, обычно Y, прогноз на конец месяца Z» и топ категорий
  против среднего за 3 месяца.
- Неполный месяц сравнивается с тем же числом дней прошлого месяца.
- Разные валюты не складываются. Без выбранной валюты — сумма отдельно по каждой.
- Страница помещается в 375 px. Светлая и тёмная темы. Подсказки открываются нажатием.
- Повторяющиеся блоки убраны или свёрнуты в `<details>`.
- Все данные экранируются. Неизвестная валюта останавливает сборку со списком строк.
- Сбой сборки по расписанию присылает сообщение в Telegram.

## 5. План

Порядок: сначала проверки и зависимости, затем ошибки в данных, затем устройство кода, затем новые
функции. Каждая задача — отдельный запрос на слияние. Каждая ошибка сначала получает
красный тест, потом исправление.

План разбит на 34 задачи на GitHub: [#9–#42](https://github.com/zovminga/family_bot/issues?q=label%3Aready-for-agent),
метка `ready-for-agent`. Задача `NN` — это issue `#(NN+8)`. Блокеры заданы связью GitHub
«blocked by». В задачах — критерии приёмки. Пункты ниже — источник для задач.
